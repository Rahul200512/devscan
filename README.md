## Tech Stack
- Next.js + TypeScript
- GitHub REST API
- Google Gemini AI (free tier)
- Tailwind CSS
- Vercel

## Run Locally
1. Clone the repo
2. Add `.env.local` with `GITHUB_TOKEN` and `GEMINI_API_KEY`
3. `npm install && npm run dev`
